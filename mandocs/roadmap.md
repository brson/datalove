# Datalove Roadmap

The MVP is a working bare datafun language with:

- documentation
- modules
- closures
- clone ops
- type aliases
- generic functions for built-in generic types
- repl, script runner
- pipeline tools
- interpreter, jit, aot
- compute-only core library
- core->runtime calls
- decent diagnostics
- heap types, examples omit
- field projections
- match for enums
