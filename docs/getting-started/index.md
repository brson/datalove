# Getting Started

Welcome to Datalove! This guide will help you get up and running quickly.

## Contents

- [Installation](installation.md) - Install the Datalove CLI
- [First Steps](first-steps.md) - Your first Datalove program

## What You'll Learn

By following this guide, you'll:

1. Install the Datalove CLI
2. Run your first Datalit program
3. Understand the basic structure of Datalove code
4. Learn how to use the REPL

## Prerequisites

- Basic command line familiarity
- Rust toolchain (for building from source)
