datalove

A simple and expressive scripting language for efficient data modeling and transformation, with a batteries included standard library.

Get Started View on GitHub

A Tower of Love

Datalove is built from three cleanly-scoped strict sublanguages of increasing power.

Datalove Literals

The tiny and comprehensible foundation. A strongly-typed pure-data language for expressing most typical data structures. A serialization format like JSON, but with rich types including tuples, structs, enums, sets, maps, option, and result.

If you understand Datalit you understand 80% of Datalove.

Datalove Functions

A simple functional language built on the datalit type system.

If you understand Datafun you understand 90% of Datalove.

Full-on Datalove

The complete language with procs, owned native pointers, and objects. The full scripting language. Dynamically interpreted or compiled. Strong typing with lightweight coercions. Task-oriented, non-async, with local heaps.

If you understand Datalove then objective achieved. It is a simple language.

Why datalove?

📚

Massive Standard Library

A battle-tested standard library with batteries included for all your data needs.

⚡

Statically Typed

Ergonomic coercions and runtime reflection make it feel flexible and fast like a dynamic scripting language.

🔄

Fast Incremental

Fast incremental compilation and execution with hot-reloading, rewind-and-replay, and rewind-and-rewrite-history.

🎯

Flexible Execution

Interpreted or compiled, JIT or AOT. Fully WASM-compatible toolchain.

💻

REPL-First Design

Built from the ground up for interactive development and exploration.

✨

First Class Types

Built-in option and result types for robust error handling.

Installation

Quick Start

  1. Create a .dls file
  2. Write your data transformations
  3. Run with datalove run script.dls
  4. Or use the REPL: datalove repl
