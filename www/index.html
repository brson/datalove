datalove

An simple and expressive typed scripting language for efficient data modeling and transformation, with a batteries included standard library.

Get Started View on GitHub

A Tower of Love

Datalove is built from three cleanly-scoped strict sublanguages of increasing power.

Datalove Literals ("Datalit")

.dlt

The tiny and comprehensible foundation of Datalove, a strongly-typed and declarative pure-data language for expressing most typical data structures.

  • A serialization format: Like JSON but with rich types including tuples, structs, enums, sets, maps, option, and result.
  • Strongly typed with free coercions: Static typing with lightweight conversions and non-destructive coercions.
  • Runtime introspection: Type shapes and descriptors are fully specified at runtime, forming the basis of the Datalove runtime ABI.
% Personal info
{
  name = "Ada",
  born = 1815,
  interests = ["mathematics", "poetry", "music"],
  address_book = set {
    struct AddressEntry {
      kind = enum Friend,
      name = "Charles",
    },
    struct AddressEntry {
      kind = enum Family,
      name = "George",
    },
  },
}

If you understand Datalit you understand 80% of Datalove.

Datalove Functions ("Datafun")

.dfs / .dfm

A simple pure-functional language that feels like an imperative language, built on the datalit type system.

  • Pure total functions: Functions on Datalit types that can't panic, always return a value.
  • Feels imperative: Familiar syntax with mutable-looking by-reference arguments, but purely functional underneath.
  • Enables powerful features: Total comptime evaluation, full or partial memoization, undo/redo, rewind/replay, and multi-determinism.
fun increment(
  accum: u64, amount: u8,
): ?u64
  ret accum +? amount
end fun

If you understand Datafun you understand 90% of Datalove.

Full-on Datalove

.dls / .dlm

The complete language with side effects, native pointers, and object abstractions.

  • Procs for side effects: proc functions that can perform I/O and modify state.
  • Owned native pointers: Linear, non-clonable tokens with provenance that the runtime can assume are unaliased.
  • Objects for abstraction: obj structs with object identity and encapsulation, the unit of abstraction in Datalove.
proc write_config(
  config: Config, path: string,
): !()
  let file = open(path, "w")?
  file.write(config.to_string())?
  ret ok()
end proc

If you understand Datalove then objective achieved. It is a simple language.

Features

Massive Standard Library

A battle-tested standard library with batteries included for all your data needs.

Statically Typed with Ergonomic Coercions

Feels flexible and fast like a dynamic scripting language, with runtime reflection.

Fast Incremental Compilation

Hot-reloading, rewind-and-replay, rewind-and-rewrite-history.

Interpreted or Compiled

JIT or AOT. Fully WASM-compatible toolchain.

REPL-First Design

Built from the ground up for interactive development and exploration.

Get Started

Installation

cargo install datalove

Quick Start

  1. Create a .dls file
  2. Write your data transformations
  3. Run with datalove run script.dls
  4. Or use the REPL: datalove repl
