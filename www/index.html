datalove

An expressive scripting language for efficient data modeling and transformation, with a batteries included standard library.

Why datalove?

⚡

Statically Typed

Ergonomic coercions and runtime introspection for confident coding.

🔄

Fast Incremental

In-place updates and REPL-first design for rapid development.

✨

First Class Types

Built-in option and result types for robust error handling.

Three Flavors, One Language

Datalove Literals

.dle

For storage and transmission of structured and optionally typed data. Like JSON, but better. All plain old data without cycles.

Datalove Modules

.dlm

A strict superset of Datalove Literals for modular code organization.

Datalove Script

.dls

The full scripting language. Dynamically interpreted or compiled. Strong typing with lightweight coercions. Task-oriented, non-async, with local heaps.

Type-Safe Scripting

let data = load("config.dle");
let result = transform(data)
  |> validate()
  |> process();

match result {
  Ok(value) => print("Success: {value}"),
  Err(e) => print("Error: {e}")
}

Installation

cargo install datalove

Quick Start

  1. Create a .dls file
  2. Write your data transformations
  3. Run with datalove run script.dls
  4. Or use the REPL: datalove repl
